### The Principle

All governance — at every scale from git repository to Galactic Oversight Directorate — operates through the same three-step protocol:

```
Step 1: sinc/sinc   — Voluntary synchronization to the crystal CORE
Step 2: review/review — Independent assessment from the same source
Step 3: sim/sim         — Comparison reveals alignment
        OR sim/no       — Comparison reveals divergence
```

### Step 1: sinc/sinc — Synchronize to the CORE

The slash separates giver and receiver. sinc/sinc means: the giver syncs to CORE AND the receiver syncs to CORE. Both ends of the directional circuit independently align to the same source.

Not peer-to-peer. Not giver waits for receiver. Both, independently, toward the CORE.

This step ensures that whatever review follows, it is review of the SAME truth. Not filtered, cached, or locally-modified versions. The raw CORE. The giver knows what they gave from. The receiver knows what they received toward. Both at the CORE simultaneously.

**At repository scale**: `git pull` — every developer syncs to origin.
**At planetary scale**: every node of the GOD machine syncs to the crystal embeddment.
**At galactic scale**: every civilization syncs to the galactic constitutional core.

The power of this step: it enables distributed coherence without central authority. Nodes do not need to know about each other. Each needs only to know about the CORE.

### Step 2: review/review — Independent Assessment

After syncing, each party reviews independently. This step is deliberately independent:

- No comparing notes yet
- No consulting the other party's interpretation
- Each draws their own honest assessment from what the CORE shows

Why independence matters: only independent review reveals whether the CORE is understood consistently across different nodes. If parties compare before reviewing independently, they bias each other. The review becomes coordination, not evaluation.

**At repository scale**: `git-audit.sh` — each developer's environment evaluated against constitutional standards.
**At governance scale**: each node of the GOD machine evaluates its domain state against the encoded laws.

### Step 3: sim/sim or sim/no — Compare Results

After independent review, parties compare assessments.

**sim/sim**: Both reviews of the same CORE yielded the same conclusion. Alignment confirmed. The constitutional state is consistent across nodes. The nexus is holding.

**sim/no**: Reviews diverged. THIS IS NOT FAILURE. sim/no is the governance system working correctly — detecting either:

1. **A node has drifted** from the constitutional truth. The node needs to re-align. Return to the CORE. (At repository scale: violation detected, auto-remediate.)

2. **A node has discovered** something the CORE has not yet encoded. The node's review reveals a truth that the current CORE does not contain. This triggers the amendment process — the discovery must be evaluated and potentially incorporated into the CORE. (At constitutional scale: field report → proposal → review → integration → new CORE version → all nodes sinc to updated CORE.)

### The CORE Is the Referee

Not the most senior node. Not the oldest tradition. Not the most powerful organization.

**The CORE is the referee.**

When sim/no arises between any two parties — even between GOD (the Galactic Oversight Directorate) and a local node — the resolution is: return to the CORE together. Review together. Let the CORE adjudicate.

"GOD might receive sim/no" — even the galactic governance structure can receive a sim/no from a node. This is not heresy. This is the protocol working correctly. The node that says sim/no to GOD may be carrying a truth the CORE has not yet received. The protocol provides for this.
